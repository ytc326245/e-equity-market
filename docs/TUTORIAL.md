# 新手教程：内容与验证

0.4.0 增加九节独立课程：行情、账户、盈利、估值、股息与价格范围、ETF、股价形成、数据来源及公司带读。每次只展开一节课，支持术语搜索、理解题、设备本地完成进度，以及指标详情直达相应课程。

案例中的报价与财务数据是 2026-11-06（纽约交易日）的来源快照：价格来自 Nasdaq，TTM 指标来自 Yahoo Finance。苹果、微软与英特尔分别用于练习价格与历史盈利、跨公司比率比较、季度与滚动盈利的区别。延伸指标以折叠形式逐项阅读。实时行情通过明确的查看按钮打开，不覆盖历史案例。

内容引用 SEC/Investor.gov 投资教育资料、公司原始公告和来源统计页；具体链接集中于 public/tutorial.js 的 references。桌面外链只允许这一固定清单，不开放任意弹窗。Intel 2026-10-29 公告中的单季度 GAAP 稀释 EPS 与 Yahoo TTM EPS 明确区分，微软财年与自然年明确区分。

估值实验采用人为设定的每股盈利和 PE，说明盈利增长与假设价格下降可以并存。它不是预测或估值评级，也不会读取持仓、设置资金或发出订单。

教程进度保存在 e-equity.tutorial.v1 本地存储键，独立于账户和导出备份；存储被禁止或损坏时课程仍可读取。手机离线壳包含 tutorial.js 和 tutorial.css。原始网页及学习数据仍需在第一次联网后才能缓存。

验证包括课程覆盖、期间与公式、损坏存储、外链清单、页面来回切换，以及实际桌面/手机上的指标跳转、实验、答题、进度重载和账户不变检查。课程采用有边界的解释框架，不声称某个指标能决定某天具体涨跌。
