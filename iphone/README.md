# 纸上美股 · iPhone 1.0.2

独立运行的 iPhone 网页应用，支持添加到主屏幕。使用时不需要 Windows 电脑开机。

## 开始使用

1. 在 iPhone 的 Safari 打开发布地址。公开入口无需注册或登录 ChatGPT。
2. 在 Safari 分享菜单中选择“添加到主屏幕”。如果有“作为网页 App 打开 / Open as Web App”选项，请开启。
3. 建议先从主屏幕打开，再在“账户”中设置虚拟本金，或导入电脑版 JSON 备份。
4. 在“交易”搜索股票 / ETF，选择买入或卖出，输入金额 / 股数，确认后按新读取的真实报价模拟成交。

## 账户保存

- 本金、持仓、自选和交易记录保存在手机浏览器的 IndexedDB，不上传到服务器。
- 网站服务器只提供公开行情、上市目录和市场时间；下单时仅发送股票代码。资金计算与保存都在手机本地完成。
- 手机和电脑不会自动同步；通过兼容的 JSON 备份进行转移。
- “账户”页面可以导出备份或恢复备份；恢复前会在本地自动存档当前账户。
- 请固定使用同一个浏览器 / 主屏幕入口，并定期导出备份。清理该网站数据或删除浏览器数据会移除本地记录。

## 行情与交易

- 使用 Nasdaq 的公开真实报价与图表，可能存在延迟，不保证与券商实时价格完全一致。
- 仅在美股正常交易时段开放模拟买卖，保留 2026–2028 年假日与提前收盘日历、夏令时处理。
- 提交前由服务器检查市场时间，并重新读取报价。软件读取完成超过 60 秒、报价无效、资金不足、超卖或休市时不成交。
- 读取时间不等于行情时间；两者分别显示，交易记录中也会保留。
- 离线时可查看本地账户、导出备份；行情需要网络，离线不会生成交易。
- 零模拟手续费，支持小数股；不模拟分红、拆股、融资和期权。

## 构建与验证

基于 Sites Vinext starter。`scripts/sync-equity.mjs` 从上级桌面项目同步交易账本规则、交易日历、行情读取逻辑、股票目录和基础界面。

```text
node scripts/sync-equity.mjs
node --test tests/mobile.test.mjs
npm run build
```

已使用 IndexedDB 测试实现验证持久化、多个标签页并发、账本与备份兼容、网络失败及正常交易时间限制；已检查构建后的实际 HTTP 页面和真实报价接口。尚未在实体 iPhone 上实测。

网页外壳可离线缓存，API 与报价不做离线缓存。发布入口保留现有公开访问设置。没有 App Store 安装包，主屏幕版本由 Safari 安装。
